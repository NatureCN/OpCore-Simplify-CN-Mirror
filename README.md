# OpCore Simplify · CN Mirror

本项目是 [lzhoang2801/OpCore-Simplify](https://github.com/lzhoang2801/OpCore-Simplify) 的**非官方分支**<br>
为其添加选择加速下载镜像的功能，**更适合中国大陆宝宝体制**，过多的就不展开了<br>
当你遇到使用官方工具时候下载进度条焊死、反复报错timeout超时等网络问题的时候，可以尝试使用本分支<br>
直接使用本分支也是可以的，因为也可以选择直链下载<br>
**其余功能与上游一致**，与原作者无关，未获其背书。<br>

## 说明
如上面所言，由于经常帮助朋友安装黑苹果（制作EFI），导致我受够了原版工具的网络速度和经常的超时报错，故此向大肥鱼大人许愿，制作了这份分支版工具<br>
工具的使用和原先一致，区别是运行后会给你一个选择镜像的页面，也可以按推荐，自动测速并选择<br>
ps：本分支工具和原版都依赖python，如果开始的python下载很慢，你可以去python的官网手动复制下载链接，然后使用如某雷之类的下载加速器下载，这样会比较快<br>

上游文档链接：<https://github.com/lzhoang2801/OpCore-Simplify>
