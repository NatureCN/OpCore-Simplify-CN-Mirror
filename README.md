# OpCore Simplify · CN Mirror

本项目是 [lzhoang2801/OpCore-Simplify](https://github.com/lzhoang2801/OpCore-Simplify) 的非官方分支<br>
为其添加选择加速下载镜像的功能，更适合中国大陆宝宝体制，过多的就不展开了<br>
当你遇到使用官方工具时候下载进度条焊死、反复报错timeout超时等网络问题的时候，可以尝试使用本分支<br>
（直接使用本分支也是可以的，因为也可以选择直连下载）<br>
其余功能与上游一致。与原作者无关，未获其背书。<br>
